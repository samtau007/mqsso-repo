# muslimquotient

One private ID and one picture across Muslim platforms.

- `docs/PRD.md`: the product and build plan. Start here.
- `docs/DEVELOPER_GUIDE.md`: what any platform (ours included) follows to connect.
- `docs/DECISIONS.md`: what has been settled, and by whom.
- `CLAUDE.md`: working rules for Claude Code.
- `app/`, `components/`, `lib/`: the muslimquotient.com starter (landing, sign-up, five questions, result). Milestone M2 moves it onto the sign-in service built in M1.

## First steps

1. Read the three docs.
2. Milestone M0: create the Postgres project, set up domains, settle decisions 2 to 4 in the PRD.
3. Milestone M1: build the sign-in service and developer portal.
